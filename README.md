**Ufficio Assenteismo e Produttività Apparente**

*Il software che lavora per non lavorare.*

A proudly unnecessary desktop application by **Animal Software House**.

## What does it do?

Calboni monitors mouse inactivity and moves the cursor to a random screen position after a configurable interval.

That's it. That's the product.

## Features

- Configurable idle time
- Random cursor movement
- Automatic screen-size detection
- Start/Stop controls
- Cross-platform Python/Qt application
- Absolutely no measurable increase in productivity

## Technology

- Python
- PySide6
- PyAutoGUI
- PyInstaller

Calboni is a humorous personal project. It is not designed or guaranteed to bypass workplace activity monitoring.
